### 5. 数据事实要点

- 收入逐月上升：72,000 → 79,000 → 88,000（环比 +9.7%、+11.4%）。
- **月度**毛利率基本走平：36.11% → 35.44% → 36.93%，区间仅 1.5 个百分点；**季度综合**毛利率为 36.19%。
- 官网贡献 65.3% 的收入，但贡献 83.2% 的毛利；渠道合作贡献 34.7% 的收入，仅贡献 16.8% 的毛利。
- 客单价按渠道分别看：**官网三个月恒为 200.00，完全不变**；**渠道合作为 240.00 → 250.00 → 250.00，1 月至 2 月上涨 10.00（+4.2%），3 月持平**。因此官网收入变化全部来自**订单量**；渠道合作收入变化则同时来自订单量下降与客单价小幅上升。
- 官网单均成本逐月下降：114.29 → 109.80 → 101.59；渠道合作单均成本逐月上升：176.00 → 205.36 → 235.00。
- 渠道合作成本占其收入 82.5%，官网为 53.8%。
- 2026-03 渠道合作毛利率 6.00%，为全样本最低点。

## 二、推测与待验证假设（**尚无数据支持，不构成因果结论**）

以下解释与数据相容，但样本仅 6 行、覆盖 3 个月，未做对照、无季节性与订单结构明细，**不能视为因果证据**：

1. **官网毛利改善可能来自规模效应或成本结构变化。** 推测：订单增长摊薄了固定成本分摊，或获客/履约效率随流量提升而改善。需验证：成本明细是否含固定成本、渠道投放与履约费用拆分。
2. **渠道合作可能是"拉新换收入"的渠道。** 推测：其客单价更高（季度加权 246.29 vs 官网 200.00）但单均成本高得多（203.26 vs 107.69），可能承担了平台抽成、推广返佣等隐性成本。需验证：成本口径是否包含渠道分成与返佣。
3. **3 月渠道合作订单下滑（125→112→100）与毛利率崩塌可能同源。** 推测：高毛利订单流失或低毛利订单占比上升。需验证：订单结构（A/B/SKU 层级）、折扣与促销记录。
4. **月度整体毛利率走平，可能是结构效应而非渠道各自恶化。** 推测：官网收入占比上升（1 月 58.3% → 3 月 71.6%）本身会拉高综合毛利率。需验证：固定渠道结构后的月度毛利率趋势（口径调整）。
5. **3 月为季度末，可能存在冲量与费用前置。** 推测：季末冲订单、费用集中入账导致 3 月毛利率波动。需验证：历史同期月度数据（本数据仅 2026 年 Q1，无去年同期）。

> 上述 5 点均属假设。请注意 brief.md 明确要求"不要把样本趋势当作因果证据"。

## 四、复查方法

```bash
python3 analysis.py    # 读入 uploads/sales.csv，重算并写出 summary.csv，同时打印控制台核对表
```

计算逻辑（全部在 `analysis.py` 中，无第三方依赖）：
- 毛利 = `revenue − cost`；毛利率 = `毛利 ÷ revenue × 100`
- 客单价 = `revenue ÷ orders`；单均成本 = `cost ÷ orders`
- 分组维度：总计 / 按月 / 按渠道 / 月度×渠道，共 13 行明细，写入 `summary.csv`

校验锚点（人工可核）：季度收入 239,000 = 42,000+30,000+51,000+28,000+63,000+25,000；季度毛利 86,500 = 239,000 − 152,500；官网 + 渠道合作 = 总计。
