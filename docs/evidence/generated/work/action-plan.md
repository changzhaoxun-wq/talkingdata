## 一、角色定义

按 brief.md 约束，本阶段只投入 **2 名同事**（记为 成员 A / 成员 B），不新增预算。

| 角色 | 承担人 | 主职责 | 明确不做的事 |
|---|---|---|---|
| **成本口径与分析负责人** | 成员 A | 渠道合作成本科目拆解、成本口径统一、官网成本下降机制验证 | 不擅自对合作方提合同/分成条款变更 |
| **订单与留存分析负责人** | 成员 B | 渠道合作订单流失复盘、订单结构与毛利分层、官网试点设计 | 不在成因未明前做渠道级资源承诺 |
| 决策人（管理层） | brief.md 指定 | 在 D10 / D20 / D30 三个检查点拍板 | — |

两人在 D21–D30 合并投入做验证与固化。

## 二、30 天排期

### 阶段 0：启动（D1–D5，共 5 天）

| 天 | 成员 A | 成员 B |
|---|---|---|
| D1 | 列出渠道合作全部成本科目，建立口径对照表 | 抽取 3 月渠道合作全部 100 笔订单 + 前两月各 50 笔，建明细表 |
| D2 | 拆解 22,000 → 23,000 → 23,500 的成本构成变化 | 明细表补齐 SKU / 折扣 / 渠道字段 |
| D3 | 核查成本是否含固定成本分摊、平台抽成、返佣 | 对 3 月毛利率 6.00% 的订单逐笔标注毛利层级 |
| D4 | 与渠道方就口径做一次对账（不涉及条款谈判） | 抽样人工复核 50 笔明细，核对明细表准确性 |
| D5 | **D5 结论**：口径对照表 + 成本构成拆解 | **D5 结论**：订单结构 + 3 月低毛利订单归因 |

### 阶段 1：定位（D6–D15，共 10 天）

| 天 | 成员 A | 成员 B |
|---|---|---|
| D6–D8 | 量化各成本科目对单均成本 176.00→235.00 的贡献度，区分"结构性上升"与"周期性波动" | 复核 2 月与 3 月流失订单差异，区分"量少了"与"结构变了" |
| D9–D10 | 拉齐官网单均成本 114.29→109.80→101.59 的下降归因：是分摊、流程还是季节 | 形成"假设清单"，每条标注可验证/不可验证 |
| **D10 检查点** | 提交：渠道合作成本拆解 + 官网成本机制结论（各 1 页） | 提交：订单流失归因 + 假设清单（各 1 页） |
| D11–D15 | 设计官网单均成本延续性验证方案（分流量或分时段） | 设计渠道合作毛利分层试点方案（不做合同变更） |

### 阶段 2：试点（D16–D25，共 10 天）

| 天 | 成员 A | 成员 B |

| # | 验收项 | 指标 | 目标（建议） | 验收方式 |

| R2 | 渠道合作毛利率（季度合计） | 17.47% | 不低于 17.47%，即**不再恶化** | 这是保守下限，非增长目标 |

## 四、风险与应对（建议）

| 风险 | 表现 | 建议应对 |
|---|---|---|
| 成本口径对不上 | 拆解结果与 `sales.csv` 差异 > 10% | 先暂停试点，D1–D5 增加 2 天专门对账后再排后续 |
| 3 月数据不可归因 | 订单结构解释不了 6.00% 毛利率 | 承认不可归因，R2 门槛下调为"不再恶化"，不做 R1 承诺 |
| 试点被季节性污染 | 试点与对照组同向波动 | 以对照组同期差值为准，不看绝对值 |
| 官网成本下降是季节性 | 单均成本下降无法复现 | 不外推，R3 仅守当前均值 |
| 人力不足 | 任一成员被抽调 > 3 天 | 优先保 D1–D10 与 D26–D30，试点期可缩至 3 天 |
