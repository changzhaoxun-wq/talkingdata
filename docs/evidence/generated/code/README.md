# 工时计费计算器

一个无需安装任何依赖、可离线打开的单文件网页，用于按工时计算应付金额。

## 使用

直接用浏览器打开 `index.html` 即可（双击本地文件，不需服务器、无外网请求）。

## 输入项

| 项目 | 说明 |
| --- | --- |
| 正常工时 | 小时数，非负数 |
| 加班工时 | 小时数，非负数 |
| 时薪 | 元/小时，非负数 |
| 加班倍数 | 倍数，非负数（1.5 表示时薪的 1.5 倍） |

## 计算规则

- 正常工时费 = 正常工时 × 时薪
- 加班工时费 = 加班工时 × 时薪 × 加班倍数
- 应付总金额 = 正常工时费 + 加班工时费

金额以人民币（¥）显示并保留两位小数，随输入实时更新。

## 导出 CSV

点击「导出 CSV」按钮，下载当前输入与计算结果：

- 中文表头：`正常工时(小时), 加班工时(小时), 时薪(元/小时), 加班倍数, 正常工时费(元), 加班工时费(元), 应付总金额(元)`
- 第二行为当前输入值与计算结果（金额保留两位小数），末行附「导出时间」
- 文件以 **UTF-8 BOM**（`EF BB BF`）开头，Excel 直接双击打开中文不乱码
- 文件名形如 `工时计费_20261121_0859.csv`
- 存在非法输入时不导出，并在状态栏提示「存在非法输入，请先修正后再导出 CSV。」

## 校验

任一输入为空、非数字或为负数时，该项标红并显示错误提示，总金额显示为「—」，避免输出错误结果。

## 验证记录

- 计算函数 `computePay` 已用 Node.js 提取执行测试：8/2/50/1.5 → ¥550.00；全零输入 → ¥0.00；7.5/3.25/120.5/2 → ¥1687.00；0/10/33.33/3 → ¥999.90，全部通过。
- 输入校验 `parseNumber` 已测试：负数、非数字、空值均判为非法并给出中文提示，`0`、`3.5`、`1e2` 判为合法。
- 页面脚本通过 `node --check` 语法检查。
- 用自建 DOM mock（环境无 jsdom）模拟运行：默认输入显示 ¥550.00（正常 400.00 + 加班 150.00）；改为 10/0/88.5/2 显示 ¥885.00；时薪填 -5 时显示「—」并提示修正。
- 导出逻辑已实测：Blob 类型为 `text/csv;charset=utf-8;`，内容前 3 字节为 `EF BB BF`（BOM 生效），表头与数据行为中文且金额为两位小数；时薪为负时未生成文件并给出提示。
- 修复：导出按钮事件曾被误写在「恢复默认值」回调内部，导致首次打开不点重置就无法导出。现已将 `exportBtn` 绑定移到脚本顶层，`resetBtn` 回调恢复为「重置并刷新」。DOM mock 复测确认：页面加载即完成两个按钮的 click 绑定，不点重置直接点导出即可生成带 BOM 的 CSV；负值时仍拒绝导出，重置功能正常。
